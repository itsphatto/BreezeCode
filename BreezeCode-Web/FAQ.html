Frequently asked questions

Everything you might want to know before you download.

Getting started

Is Breeze Code free?

Yes. Breeze Code is free to download and use, with no plan or credits. If you pick a paid AI agent, that agent's provider bills you for it.

What do I need to run it?

A PC running Windows 10 or Windows 11 (64-bit). The installer is around 110 MB.

To run code, Breeze uses the tools already on your computer, such as Python, Node.js or a C/C++ compiler. If something is missing, it tells you what to install.

Is there a Mac or Linux version?

Not yet. Breeze Code is Windows-only for now.

Windows says "Windows protected your PC". Is it safe?

The installer isn't code-signed yet, so Windows SmartScreen shows a warning for it. Click More info, then Run anyway to continue.

Only download Breeze Code from the official GitHub releases page.

I've never used an AI agent. Is Breeze for me?

Yes. An AI agent is a program that can read your project, write code and run commands for you when you ask in plain words. Breeze shows every file it reads, every edit and every command as it happens, so you can follow along and learn from what it does.

Do I need to sign in or make an account?

No. Signing in with GitHub or Google is optional, and there is no Breeze Code account. If you do sign in, your sign-in details are encrypted and stay on your computer.

Do I need Git or Node.js?

First-run setup checks whether they are installed. Git powers checkpoints and Source Control, and Node.js runs JavaScript. You can install them later if you need those features.

AI agents

Which AI agents does it work with?

During setup, Breeze looks for Claude Code, Codex and Antigravity on your computer. You can also run a local model through Ollama, LM Studio or any OpenAI-compatible server.

You can switch agents at any time in Settings.

Do I need an AI agent to use it?

No. The editor, terminal, Git tools and live preview all work on their own. Agents are there when you want them.

How do I use a local model?

Start Ollama, LM Studio or another OpenAI-compatible server on your computer, then pick it during setup or in Settings. With a local model, your prompts and code never leave your machine.

Can I use more than one agent on the same task?

Yes. @mention different agents in one prompt, even from different companies, and give each one part of the task. Each agent claims its files, you settle any overlap, and then they build at the same time.

What if two agents try to edit the same file?

If one agent edits a file another agent owns, Breeze puts the file back and tells you, so one agent can't quietly overwrite another's work.

Can I undo what an agent did?

Yes. Git checkpoints let you step back from a change you don't like. Always review an agent's changes before you rely on them, and keep backups of work that matters.

Privacy and safety

Does my code leave my computer?

Your files stay on your machine. With a local model, nothing leaves your computer at all.

If you use a cloud agent like Claude Code, Codex or Antigravity, that agent sends what it needs for a task to its provider, under that provider's terms.

Where are my API keys stored?

API keys and sign-in tokens are encrypted with Windows' built-in protection and saved only on your computer. They are sent only to the provider they belong to.

Does Breeze Code collect telemetry?

No. The app doesn't send usage data or crash reports, and there are no ads. Read the Privacy Policy for the full details.

Features

Which languages can I run?

Press F5 to run Python, C, C++ and C# files. JavaScript runs on Node in the integrated terminal, and HTML and CSS get a live preview beside the editor.

Java and Rust support is on the way.

What is Vibe Code Mode?

Agents can take a few minutes. In Vibe Code Mode, the IDE fades and an Instagram or Facebook Reels feed plays while the agent works. A card tells you when your code is ready, and you decide when to leave.

What is Breeze Box?

Breeze Box is just a prompt and a chat, with no editor. Code in a reply becomes an artifact card that you can copy or download in one click.

Is it heavy on my computer?

Breeze is built to be light, not a heavy IDE. By our rough estimate it can use up to 12× less memory than heavier AI editors, though your numbers will depend on your projects and agents. The editor draws only the lines on screen, so large files stay quick to scroll and edit.

Can I use it without an internet connection?

The editor, terminal, Git tools and live preview work offline, and so do local models. Cloud agents, update checks and sign-in need an internet connection.

Updates and help

How do updates work?

Breeze checks for a new version when it starts and asks before downloading anything. Once downloaded, the update installs when you close the app, or right away if you choose to restart.

Can I use Breeze Code for work or school?

Yes. The code you write is yours, and Breeze is free for personal, school and commercial use. The Terms of Service cover the details.

Where can I report a bug or ask for a feature?

Open an issue on GitHub. Please include your Breeze version and what you were doing when it happened.

For privacy or legal questions, email BreezeCodeSupport@gmail.com.
