Got questions?

The stuff people usually ask before hitting download.

Getting started

Is Breeze Code free?

Yep, totally free. No plans, no credits. If you pick a paid AI agent, its provider bills you, not us.

What do I need to run it?

A Windows 10 or 11 PC (64-bit). The installer's about 110 MB.

To run code, Breeze uses what's already on your PC, like Python, Node.js or a C/C++ compiler. Missing something? It'll tell you what to install.

Is there a Mac or Linux version?

Not yet. Windows only for now.

Windows says "Windows protected your PC". Is it safe?

The installer isn't code-signed yet, so SmartScreen gets nervous. Click More info, then Run anyway.

Just make sure you got it from the official GitHub releases page.

I've never used an AI agent. Is Breeze for me?

Absolutely. An AI agent reads your project, writes code and runs commands when you ask in plain words. Breeze shows every move it makes, so you can follow along and pick things up as you go.

Do I need to sign in or make an account?

Nope. Signing in with GitHub or Google is optional, and there's no Breeze Code account. If you do sign in, your details are encrypted and stay on your PC.

Do I need Git or Node.js?

Setup checks for them. Git powers checkpoints and Source Control, Node.js runs JavaScript. Grab them later if you need them.

AI agents

Which AI agents does it work with?

Setup looks for Claude Code, Codex and Antigravity on your PC. Or run a local model through Ollama, LM Studio or any OpenAI-compatible server.

Swap agents anytime in Settings.

Do I need an AI agent to use it?

Nope. The editor, terminal, Git and live preview all work solo. Agents are there when you want them.

How do I use a local model?

Fire up Ollama, LM Studio or another OpenAI-compatible server, then pick it in setup or Settings. Your prompts and code never leave your machine.

Can I use more than one agent on the same task?

Yes! @mention a few agents in one prompt, even from different companies, and give each a piece. They call dibs on their files, you settle any overlap, then they build side by side.

What if two agents try to edit the same file?

Breeze puts the file back and tells you, so nobody quietly overwrites anyone's work.

Can I undo what an agent did?

Yep. Git checkpoints let you hop back from any change you don't like. Still, give an agent's work a look before you rely on it, and back up anything important.

Privacy and safety

Does my code leave my computer?

Your files stay home. With a local model, nothing leaves your PC at all.

Cloud agents like Claude Code, Codex or Antigravity send what they need for a task to their provider, under that provider's terms.

Where are my API keys stored?

Encrypted by Windows' built-in protection and saved only on your PC. Each key only ever goes to the provider it belongs to.

Does Breeze Code collect telemetry?

Nope. No usage data, no crash reports, no ads. The Privacy Policy has the full story.

Features

Which languages can I run?

Hit F5 to run Python, C, C++ and C#. JavaScript runs on Node in the terminal, and HTML and CSS get a live preview right beside your code.

Java and Rust are coming.

What is Vibe Code Mode?

Agents can take a few minutes, so the IDE fades and an Instagram or Facebook Reels feed rolls while you wait. A card pops up when your code's ready. Head back whenever you like.

What is Breeze Box?

Just a prompt and a chat, no editor. Code in a reply turns into a card you can copy or download in one click.

Is it heavy on my computer?

Nope, it's built light. By our rough estimate it can use up to 12× less memory than heavier AI editors (your mileage depends on your projects and agents). Only the lines on screen get drawn, so big files stay snappy.

Can I use it without an internet connection?

Mostly! The editor, terminal, Git, live preview and local models all work offline. Cloud agents, update checks and sign-in need the internet.

Updates and help

How do updates work?

Breeze checks for a new version on launch and asks before downloading. It installs when you close the app, or right away if you restart.

Can I use Breeze Code for work or school?

Go for it. Your code is yours, and Breeze is free for personal, school and commercial use. The Terms of Service have the fine print.

Where can I report a bug or ask for a feature?

Open an issue on GitHub. Tell us your Breeze version and what you were up to when it happened.

Privacy or legal stuff? Email BreezeCodeSupport@gmail.com.
