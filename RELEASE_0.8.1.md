## Breeze Code 0.8.1

Gemini and OpenRouter join your agents, the model picker shows who made each model, and agents show their to-do lists as they work.

### New

- **Gemini and OpenRouter agents.** Set them up from new cards in Setup, with logos and model marks. They join agent detection, teams, the board and commits. Breeze checks your OpenRouter key and defaults to a cheaper model. Each API provider keeps its own saved config, and saved model lists refresh.
- **Agent to-do lists.** An agent's plan shows as a step card while it works.
- **Next-line suggestions** in the editor.
- **Pinned chats.** Pin chats in the Agent Board side bar.
- **Model picker logos.** The picker shows each maker's logo and lists every agent's models.

### Improved

- **Completion list.** LSP completions are filtered by what you have typed.
- **Chats reopen at the latest message** instead of the top.
- **Skill explanations** (`/` in the Agents tab and the board) pop up to the side.
- **One glass style.** Popups and dropdowns share a single 90% solid sheet.
- **Board look.** Refined chips, side bar and drop styling. *(by @Sapfire151)*
- **Home page.** The prompt box sits lower and the GitHub graph no longer drags.
- **Triangle hovering** for easier menu navigation.
- **Large inputs.** Removed quadratic and unbounded work. *(by @Sapfire151)*

### Changed

- The agents chip in the agent side bar is gone.
